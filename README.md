# 🚀 SwiftSync

SwiftSync - это современное, быстрое и удобное приложение для копирования файлов с графическим интерфейсом, разработанное на Python с использованием PySide6 (Qt).

![Python Version](https://img.shields.io/badge/python-3.6+-blue.svg)
![PySide Version](https://img.shields.io/badge/PySide6-6.0+-green.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

## ✨ Особенности

- 🎯 Интуитивно понятный графический интерфейс
- 📊 Отображение прогресса копирования в реальном времени
- ⚡ Показ скорости копирования и оставшегося времени
- 📁 Возможность выбора нескольких файлов
- 🔄 Отображение общего размера выбранных файлов
- ⏸️ Возможность отмены операции копирования
- 🎨 Современный дизайн в стиле Material Design

## 🛠 Установка

1. Убедитесь, что у вас установлен Python 3.6 или выше
2. Клонируйте репозиторий:
3. Установите зависимости:
```bash
pip install PySide6
```

## 🚀 Использование

Запустите приложение командой:
```bash
python file_copier.py
```

### Порядок работы:
1. Нажмите кнопку "Выбрать файлы" для выбора файлов для копирования
2. Выберите один или несколько файлов в диалоговом окне
3. Нажмите кнопку "Копировать файлы"
4. Выберите целевую директорию для копирования
5. Следите за прогрессом копирования в реальном времени

## 📊 Возможности мониторинга

- Отображение общего размера выбранных файлов
- Показ текущей скорости копирования
- Индикация прошедшего времени
- Расчет оставшегося времени
- Отображение средней скорости после завершения
- Визуальный прогресс-бар

## 🎨 Пользовательский интерфейс

- Современный минималистичный дизайн
- Интуитивно понятное расположение элементов
- Цветовая индикация статуса операций
- Адаптивный размер окна
- Поддержка тем оформления Qt

## 🔧 Технические детали

- Использование потокобезопасного копирования файлов
- Эффективное управление памятью при копировании больших файлов
- Корректная обработка ошибок и исключений
- Оптимизированное чтение и запись файлов блоками
